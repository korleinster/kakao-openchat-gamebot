## 1. 목적과 범위

일정 알림 사이에 방 사람들이 설명 없이 참여할 수 있는 짧은 놀이를 제공한다. 1차는 텍스트 뽑기·주사위, 2차 후보는 퀴즈·숫자 맞히기·경마, 별도 검증이 필요한 확장 후보는 캐치마인드다.

## 2. 뽑기

| 입력 제안 | 동작 | 예외 |
| --- | --- | --- |
| !뽑기 이름1 이름2 이름3 | 입력한 후보 중 1명 추첨 | 후보 2명 미만이면 사용법 안내 |
| !뽑기시작 | 방별 참가 세션 생성 | 진행 중 세션이 있으면 새 세션 생성하지 않음 |
| !참가 | 현재 세션에 표시 이름으로 참가 | 같은 표시 이름은 1회만 등록하는 초기 안 |
| !뽑기종료 | 참가 마감·추첨·결과 출력 | 참가자가 없으면 당첨자 없음 |

참가 제한 시간 제안은 60초. 종료가 이미 처리된 세션은 같은 결과를 재조회할 수 있어도 새 추첨으로 바꾸지 않는다. 결과 생성과 세션 완료를 한 트랜잭션으로 저장한다. 전송 결과가 불명확하면 결과를 다시 뽑지 않고 앱에서 상태를 확인한다.

후보 집합을 먼저 고정한 뒤 편향 없는 난수로 선택한다. 비슷한 이름을 임의로 같은 사람으로 합치지 않는다. 알림만으로 전체 방 인원을 알 수 없으므로 '방 전체에서 공정하게 추첨'이라고 표현하지 않고 입력 후보·참가 신청자에서 추첨했다고 표시한다.

닉네임 변경·동명이인·같은 계정 여부를 알림만으로 확실하게 판정할 수 없다. 1차 놀이의 참가 단위는 검증된 계정 ID가 아니라 해당 세션의 표시 이름이다. 금전·상품 지급이나 계정 단위 공정성을 보장하는 추첨으로 사용하지 않는다.

## 3. 주사위·기타 후보

!주사위는 1~6, !주사위 N은 1~N. N 범위와 방별 호출 간격은 실기기 메시지 부담을 보고 정하는 설정값으로 둔다. 잘못된 입력·범위 밖 입력은 추첨하지 않고 사용법을 안내한다.

숫자 맞히기·퀴즈·경마를 추가할 경우 문제·정답·참가 상태를 게임 세션으로 분리한다. 앱이 재시작하면 진행 중 세션을 종료하고 복구 안내는 다음 유효한 명령에 답하는 안을 제안한다. 재시작 직후 게임 안내를 일괄 발송하지 않는다.

## 4. 캐치마인드 선택지

| 안 | 참여 방식 | 남은 검증 |
| --- | --- | --- |
| 사람이 그림 업로드 + 봇이 텍스트 답 판정 | 출제자는 직접 카톡에 그림을 올리고 참여자는 채팅으로 답 입력 | 출제자에게 정답을 안전하게 전달·등록하는 경로 |
| 별도 웹 그림판 | 카톡에 참여 링크 공유, 그림·정답은 웹에서 처리 | 로그인·방 연결·호스팅·모바일 사용성 |
| 봇이 그림을 직접 전송 | 준비된 이미지 또는 생성 이미지를 방으로 전송 | 비공식 이미지 전송의 현재 지원·호환성·권한 |

텍스트 답장 경로가 검증됐다고 이미지 전송까지 된다고 해석하지 않는다. 초기 개발 계획에는 방 안의 직접 그림 전송을 필수 조건으로 넣지 않는다.

## 5. 알림과 게임의 관계

같은 방의 텍스트 전송 큐는 공유하되 시스템 일정 알림을 우선 처리한다. 게임 메시지가 몰려 5분 전 알림의 유효시각을 넘기지 않게 방별 대기열 길이와 호출 간격을 제한한다. 봇 자체 메시지가 다시 명령으로 들어와 반복되는 상황을 차단한다.

운영 설정·전체 기록 삭제·일정 수정은 채팅 닉네임 권한으로 실행하지 않는다. 사용자 입력을 자바스크립트·명령 실행 코드로 평가하지 않고 허용된 명령만 해석한다.
