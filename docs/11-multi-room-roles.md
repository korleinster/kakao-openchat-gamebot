문서 상태: 다중 방·역할 분리 0.2.0-test 구현·폰 설치·자동 검사 완료, 두 방 병행 실제 응답 검증 대기. 구체적인 실제 방별 역할은 사용자 답변 ‘미정’으로 유지한다.

## 1. 변경 목적

기존 한 방 연결을 여러 방의 독립 연결로 확장한다. 게임방에는 일정 안내를, 친목방에는 오락을 맡기는 등 방마다 사용하는 기능을 선택한다. 앱에서 관리 화면을 다른 방으로 바꿔도 실제 수신 대화에 맞춰 응답한다.

폰의 카카오톡 계정이 참여한 방을 앱에 각각 등록하고 코드로 연결한다. ‘새 방 추가’는 앱의 관리 대상 등록이며 카카오톡 방 생성·자동 입장 기능은 아니다. 현재 알림 기반 답장 경로를 유지한다.

## 2. 기능과 사용 흐름

| 요구사항 | 동작 | 예외·조건 |
| --- | --- | --- |
| MR-01 여러 방 등록 | 방 목록에서 새 방 이름·역할을 등록하고 연결 코드 생성 | 시험 버전은 최대 20개 등록. 한 번에 코드 연결 작업 하나만 진행 |
| MR-02 방별 연결 | 다른 계정에서 해당 방에 코드를 보내고 앱에서 확인 | 방 이름 대신 확정한 알림 식별 해시로 구분. 같은 대화 중복 등록 차단 |
| MR-03 독립 실행 | 방별 응답·정기 알림·07:00 안내 설정 | 새 방 연결 시 다른 연결 완료 방의 설정·대기 발송을 초기화하지 않음 |
| MR-04 역할 선택 | 게임 일정 알림 / 오락 / 알림+오락 | 아직 미정인 방의 역할을 임의로 운영 설정하지 않음 |
| MR-05 데이터 분리 | 방별 일정·컬렉션·명령 중복 기록·전송·처리 기록 | 같은 일정 ID·메시지 ID도 방별 독립. 다른 방으로 자동 전달하지 않음 |
| MR-06 상태 확인 | 전체 방 요약과 선택한 방의 상세 상태 표시 | 관리 화면 선택은 실제 메시지 수신·발송 대상을 바꾸지 않음 |
| MR-07 기존 연결 보존 | 기존 설정·DB를 첫 방으로 유지 | 구버전 데이터 삭제·초기화 없이 사용, 새 방만 별도 저장 |

운영 흐름: 카카오톡 방 참여 → 앱에서 ‘새 방 추가’ → 이름·역할 선택 → 다른 계정에서 코드 전송 → 앱에서 방 확인 → 해당 방 응답 켜기. 기존 방의 역할은 방 선택 후 변경한다. 역할 변경 시 해당 방의 대기 발송을 취소하고 다음 일정을 재계산하며 연결·일정 원본은 유지한다.

## 3. 초기 역할 표

| 역할 | 일정 조회·시험 알림 | 정기 일정·아침 알림 | 주사위·뽑기 | 공통 명령 |
| --- | --- | --- | --- | --- |
| 게임 일정 알림 | 사용 | 개별 설정 후 사용 | 사용 안 함 | !핑, !도움말 |
| 오락 | 사용 안 함 | 사용 안 함 | 사용 | !핑, !도움말 |
| 알림+오락 | 사용 | 개별 설정 후 사용 | 사용 | !핑, !도움말 |

도움말은 해당 방에서 허용한 명령만 표시하고 비활성 기능 명령에는 응답하지 않는다. 앱의 수동 30초 시험 버튼은 방 연결 점검용이며 역할과 별개다. 역할 선택 자체가 정기 알림을 켜지는 않는다. 오락 역할로 바꾸면 해당 방의 정기 알림을 끄고, 알림 역할로 되돌려도 사용자가 다시 켜야 한다.

초기 역할은 이미 구현한 기능의 실행 범위를 정한다. 자연어 AI 성격·외부 정보·관리자 권한·새 오락 기능은 구체 요구사항을 정한 뒤 확장한다.

## 4. 저장·처리 설계

- 방 목록에는 앱 내부 UUID와 선택 상태를 저장한다. 기존 방은 `legacy` ID로 기존 `bot-settings`와 `bot.db`를 그대로 사용한다.
- 새 방마다 별도 설정 파일과 SQLite DB를 사용한다. 일정 수정·초기화·명령 중복 판정·전송 상태가 다른 방에 영향을 주지 않는다.
- 실행 작업은 한 직렬 작업자로 처리한다. 수신 알림은 전체 방의 확정 식별자를 먼저 조회하고, 등록되지 않은 알림은 현재 코드 연결 작업에만 제한적으로 사용한다.
- 한 대화가 여러 설정에 매칭되면 관련 방 발송을 차단한다. 이미 연결된 대화에 다른 방의 코드를 보내도 새 방으로 빼앗아 연결하지 않는다.
- 전체 방 중 가장 빠른 다음 작업을 앱 알람 하나로 등록한다. 한 방의 설정 변경으로 다른 방의 알람이 없어지지 않게 한다. Doze의 앱 단위 제한은 방을 늘려도 공유한다.
- 답장 Action의 카카오톡 소유자·텍스트 입력 검증, 최신 메시지·코드 유효시간·로컬 확인, 요청 수락/실제 도착 구분을 유지한다.

## 6. 구현·설치 기록

0.2.0-test 빌드·폰 설치 완료. 계산·방 연결·역할·라우팅 단위 검사 29개 통과, 정적 검사 오류 0건. 폰의 독립 DB·설정·다중 방 저장 검사 11개 통과. 기본 폰 검사에서 실제 연결을 바꾸는 선택 검사 3개는 조건이 없어 건너뛰었으며 통과 수에 넣지 않는다.
