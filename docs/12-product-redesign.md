## 1. 목적과 변경 범위

사용자가 확정한 앱 이름은 ‘채팅봇’이다. 게임 전용 도우미에서 방별 기능을 선택하는 공용 도우미로 화면과 용어를 개편한다. 기존 방 연결·알림·독립 저장 구조를 유지하면서 역할 프리셋을 개별 기능 선택으로 바꾼다.

| ID | 사용자 요구 | 구현 기준 | 기존 데이터 |
| --- | --- | --- | --- |
| UX-01 | 역할 대신 기능 체크박스 | 반복 알림·주기 알림·아침 요약·주사위·뽑기를 독립 선택 | 기존 MIXED/FUN/GAME_ALERTS를 동등한 조합으로 읽고, 명시적으로 빈 선택을 저장하면 빈 상태 유지 |

고객문의 이메일은 제공되지 않았다. 앱 안에는 실제 공개 문의 경로인 프로젝트 Issues를 연결하고, Play Console의 지원 이메일은 제출 전 확정한다.

## 2. 화면 구성과 저장 규칙

채팅방: 방 카드에 이름·연결 상태·선택 기능·말투 표시 → 방 설정 → 봇 사용, 기능 체크박스, 말투 라디오 버튼·미리보기, 연결 관리. 체크하거나 미리보기만 바꾼 상태와 저장 완료를 구분하며 ‘기능과 말투 저장’으로 적용한다. 다른 방 설정을 바꾸지 않는다.

알림: 현재 관리할 방 선택 → 예약 발송 켜기 → 알림 목록 → 만들기·수정·사용 중지·삭제. 방의 봇 사용과 예약 발송이 켜져 있고 연결·동의·권한이 갖춰져야 발송한다. 기능만 선택했다고 기존 예약 발송을 자동으로 켜지 않는다.

설정: 접근 권한과 동의 상태, 처리방침·동의 철회·모든 데이터 삭제, 도움말·문의·라이선스. 동의를 철회하면 모든 방의 처리·발송을 중지하고, 재동의 시 설정을 다시 사용할 수 있다. 방 설정 삭제와 전체 삭제는 각각 확인 후 처리한다.

디자인: 앱 자체 채팅 말풍선·체크 아이콘, 밝은 배경과 명확한 기본 동작, 다크 모드, 시스템 글자 크기, 터치 영역 48dp 이상, Android 시스템 바 영역 여백, 기본 접근성 체크박스·라디오·스위치·날짜/시각 선택기 사용. 연결 진단은 상세 보기로 분리하고 일상 화면에는 실행 상태를 먼저 표시한다.

## 3. 기능별 조건

| 기능 | 입력·출력 | 꺼진 상태 |
| --- | --- | --- |
| 반복 알림 | 요일 체크·시각·0~1440분 전 안내. 0분이면 정각 | 해당 회차 발송·호환 조회 명령 차단 |
| 주기 알림 | 기준일·시각·1~24개월·0~90일 전 안내. 원래 월말 기준 유지 | 주기 조회·회차 발송 차단 |
| 아침 요약 | 기본 07:00, 방별 시각 변경·빈 일정 안내 선택 | 요약 생성하지 않음 |
| 주사위 | !주사위 [최댓값] | 해당 명령 무응답 |
| 뽑기 | !뽑기 후보1 후보2 ... | 해당 명령 무응답 |

공통 연결 확인·도움말은 모든 기능을 꺼도 사용할 수 있다. 도움말은 저장한 기능에 해당하는 명령만 표시한다. 공용 조회는 !오늘·!알림·!주기이며, 기존 !월보·!정기·!컬렉션은 해당 기능이 켜진 경우 호환 처리한다.

말투는 문구 표현만 바꾸고 이름·시각·숫자·추첨 결과를 바꾸지 않는다. 일정과 메시지를 판단하는 외부 AI 서비스를 도입하지 않는다. 앱의 설정 안내는 선택한 봇 말투와 별개로 일관되게 유지한다.

## 4. 개인정보·복구

카카오톡 최신 알림으로 코드와 연결된 대화의 명령을 기기 안에서 처리한다. 답장·예약 알림은 카카오톡을 통해 해당 대화로 전달한다. 전체 대화 이력을 저장하지 않는다. 설정·등록 알림은 삭제 전까지, 완료 발송·처리 기록은 7일 경과 시 앱 동작 중 정리하며 중복 확인 해시는 1일 경과 시 정리한다. 최근 처리 기록은 최대 100개다.

기존 방은 별도의 재연결 없이 유지한다. 새 동의 설명에 동의하기 전에는 기존 OS 알림 접근이 허용돼 있어도 처리·발송하지 않는다. 새 설치는 방이 없는 상태에서 시작한다. 마지막 방을 삭제해도 과거 기본 방이 되살아나지 않아야 한다.

## 5. 검증 완료 조건

- 32가지 기능 조합의 독립 명령 허용·도움말, 빈 기능 선택 보존.
- 다섯 말투의 고유 미리보기·동일 사실 값 보존, 방별 설정 독립.
- 기존 JSON 기본 안내 시간·개월 기준 보존, 0분/사용자 안내 시간·요약 시각 계산.
- 동의 전 차단·철회, 방 삭제·전체 삭제, 기록 정리와 진행 중 작업 보존.
- 실기기 업데이트 전 백업·기존 연결/기능/발송 OFF 보존, 체크박스·미리보기·저장 흐름.
- Android 16 환경의 화면 영역·뒤로가기·큰 글자·다크 모드, 실제 명령/예약 발송.

0.2.0의 실제 두 방 성공을 0.3.0 검증으로 재사용하지 않고 버전별 결과를 남긴다.

장시간 절전·앱 강제 종료·재부팅·무대화 이후 복구, 최신 OS의 실제 카카오톡 발송, 실제 일정 자료 등록은 미완료다. 테더링·USB 모드·Tailscale 설정은 변경하지 않았다.
