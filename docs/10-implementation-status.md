## 1. 시험 범위

사용자가 만든 1:1 오픈채팅방 ‘봇테스트’에서만 시험한다. 다른 카카오톡 계정에서 명령을 입력할 수 있다는 사용자 답변을 확인했다. 연결한 대화에만 답장한다. 1:1 방 연결 코드가 유효한 5분 동안은 새 알림의 최신 텍스트에서 정확한 연결 코드만 검사하며, 일치하지 않은 내용과 다른 대화 기록은 저장하지 않는다.

## 3. 개발 도구

프로젝트 전용 폴더에 Temurin JDK 17.0.21+9, Gradle 8.9, Android 명령줄 도구 19.0, 플랫폼 35, 빌드 도구 34.0.0 준비. AGP 8.7.3, Kotlin 2.0.21 사용. 공식 배포 체크섬을 확인했다. 시스템 전역 Java·SDK 설정은 변경하지 않았다.

## 4. 검증과 남은 범위

단위 검사는 한국 날짜·요일 경계, 월말·윤년·개월 주기, 늦은 안내 만료, 일정 수정 시 회차 ID 유지, 명령 입력 검증을 대상으로 한다. 기기 검사는 DB 선점 경쟁, 전송 중 중단 복구, 취소·수정된 일정 차단을 대상으로 한다.

이 시험은 테더링을 유지하고 재부팅·USB 모드 변경·네트워크 단절 시험을 하지 않는다. 화면은 평소 잠금·꺼짐 상태를 유지하고 필요한 UI 설정 때만 사용자 잠금 해제를 요청한다.

기존 디스코드 봇 서버 연동, 공식 일정의 예외 회차, 캐치마인드 그림 경로, 공개 배포용 서명·전체 배포 고지 검사는 후속 단계다. 실제 월드보스·정기 콘텐츠·컬렉션 원본은 아직 등록하지 않는다.

## 5. 빌드·실기기 기록

- 시험 APK 0.1.0-test 설치, 사용자 알림 접근 허용, 리스너 연결·정확한 알람 권한 확인.
- 단위 검사 15개 통과, 정적 검사 오류 0건. 주간 다음 회차와 먼 미래 컬렉션 예약 누락을 수정하고 회귀 검사 추가.
- 폰의 독립 시험 DB 검사 5개 통과. 실제 사용자 일정 DB를 초기화하지 않음.
- 첫 연결 코드는 수신됐지만 1:1 알림에 방 제목이 없어 기존 이름 필터가 거부했다. 사용자 1:1 방 확인 후 코드·식별 해시 방식 보완, 새 연결 코드 발급.
- 그룹 오픈채팅, 장시간 무대화, Doze·재부팅·네트워크 단절은 미검증이다.
