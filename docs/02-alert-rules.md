## 1. 알림 생성 흐름

일정 원본 → 개별 회차 → 방별 발송 항목 → 시각·데이터 유효성 재확인 → 전송 요청 → 결과 기록.

기준 시간대는 Asia/Seoul. 저장 시각은 UTC Instant로 관리하고 게임 날짜·요일 계산은 한국 시간으로 수행한다. 휴대폰 시간대를 바꿔도 게임 일정이 이동하지 않는다.

## 2. 월드보스·정기 콘텐츠

| 항목 | 처리 규칙 |
| --- | --- |
| 대상 | 활성 일정, 활성 방, 유효한 원본·회차가 모두 있는 경우 |
| 발송 시각 | 해당 회차 시작 시각에서 5분을 뺀 시각 |
| 메시지 | 콘텐츠 이름, 시작 시각, 실제 남은 시간, 필요한 입장 조건 |
| 같은 시각 | 동일 방·동일 알림 시각의 콘텐츠는 하나의 메시지로 묶되 항목별 중복 방지 상태 보존 |
| 시작 시각 도달 | 미발송 5분 전 안내를 만료 처리. 출현/시작 알림으로 임의 전환하지 않음 |
| 일정 수정 | 기존 미전송 회차·발송 항목을 갱신 또는 취소하고 새 시각 계산 |
| 비활성화·삭제 | 아직 요청하지 않은 발송 항목 취소. 발송 직전에도 최신 활성 상태 확인 |

발송 지연 제안: 예정 시각부터 60초 이내만 자동 전송 후보로 인정한다. 늦게 보낼 때는 실제 남은 시간으로 문구를 생성하며 무조건 '5분 전'이라고 쓰지 않는다. 60초를 넘으면 만료 처리한다. 이 값은 실기기 결과와 사용자 판단으로 조정한다.

## 3. 아침 일정 안내

사용자 확정 시각인 매일 07:00 Asia/Seoul로 저장한다. 실제 방 연결·일정 확인 후 사용자가 자동 발송을 켠 뒤 발송한다.

한 메시지 안에서 오늘 남은 월드보스와 정기 콘텐츠를 시작 시각 순으로 안내한다. 당일 기준은 한국 시간 00:00 이상 다음날 00:00 미만이다. 이미 시작한 항목은 '앞으로의 일정'에 포함하지 않는다.

컬렉션 항목을 아침 안내에 포함할지는 설정 제안으로 둔다. 포함 시 사전 안내 구간에 해당하는 항목만 표시하며, 동일 내용의 별도 알림과 중복되지 않게 한다.

예외: 아침 시각 이후 앱을 켠 경우 10분 이내에만 당일 안내 한 건을 보내는 안을 제안한다. 10분 이후에는 자동 과거 안내를 발송하지 않고 !오늘 조회를 제공한다. 일정이 없는 날은 '오늘 등록된 일정 없음' 발송/생략을 사용자가 선택하며 초기값은 기능 비활성 상태다.

## 4. 기간제 컬렉션

개인 캐릭터 만료일이 아닌 게임 공통 갱신 일정을 관리한다. 실제 종류와 날짜는 사용자 자료를 받은 뒤 등록한다.

| 필드 | 의미·입력 조건 |
| --- | --- |
| collection_id / name | 종류별 고유 ID와 원본 명칭 |
| basis | explicit_dates 또는 anchored_calendar_months |
| anchor_at | 기준 회차의 정확한 한국 시각. 주기 방식일 때 필수 |
| interval_months | 종류별 개월 수. 2·4는 사용자 예시이며 실제 종류를 뜻하지 않음 |
| overrides | 공식 공지에 따른 특정 회차 변경·휴회 |
| notice_offsets_days | 며칠 전 안내할지. 미정이면 비활성 |
| source / verified_at | 원본 위치, 확인 시각, 적용 회차 범위 |

계산 제안: '2개월'을 60일, '4개월'을 120일로 치환하지 않는다. 달 단위 반복을 사용할 때는 매 회차를 기준일 + n×개월로 계산한다. 월말은 대상 달의 마지막 날로 보정하되, 다음 회차 계산의 원본 기준일을 바꾸지 않는다. 예를 들어 1월 31일 기준 월 단위 테스트는 2월 말일 후 3월 31일로 돌아와야 한다. 실제 게임 규칙이 특정 점검일이라면 명시 날짜·예외 일정이 우선한다.

조회 실패·정보 미등록·갱신 필요 없음은 서로 다른 상태로 표시한다. 갱신을 실제로 완료했다고 자동 판정하거나 계정 내 컬렉션 등록을 조작하지 않는다.

## 5. 운영 메시지 원칙

- 원본 이름을 사용한다. 일정이나 입장 조건을 추정해 문구에 채우지 않는다.
- 긴 아침 안내는 문자 수·콘텐츠 수 한도를 실기기에서 측정한 뒤 분할한다. 각 분할 메시지에도 고정 part_id를 부여한다.
- 전송 연결이 없거나 권한이 없으면 단톡방을 반복 호출하지 않는다. 폰의 앱 상태 화면에 원인과 필요한 조작을 보여준다.
- 재시작·네트워크 회복 때 과거 메시지를 한꺼번에 쏟아내지 않는다.

## 6. 수용 기준

- 한국 시간 날짜 경계, 요일 변경, 기준 시각 직전·정각·직후를 각각 검증.
- 시작 5분 전 발송 항목은 하나의 회차·방에 한 번만 생성.
- 수정·비활성화된 회차를 예전 알람이 호출해도 전송하지 않음.
- 컬렉션 기준일·안내 시점 미입력 시 임의 알림 없음.
- 아침 안내와 5분 전 안내는 서로 다른 목적의 항목으로 관리.
