# Release preparation

The app targets API 36 and supports API 26+. A build or local test result does not represent store approval or production rollout.

Before release, validate upgrade/migration, offline edits, concurrent changes, lost-response retries, credential rotation, room isolation, generic endpoint setup, notification consent, and real-recipient message delivery. Test large text, dark mode, current Android versions and relevant idle/restart conditions. Use synthetic data in public screenshots.

Supply your developer account, public support contact, protected upload key and Play Console declarations. Update the privacy policy and listing assets to match the final app. Complete applicable account testing and provide a reviewer-access environment. Sign and verify the final AAB. Do not publish personal endpoint settings, device identifiers, room names, credentials, operations records or private website source.

Private project evidence is intentionally maintained outside this public source tree. See the public [privacy policy](privacy-policy.md), [protocol](sync-protocol.md) and [asset notes](../distribution/README.md).
