개인정보·대화 원문·연결 코드를 공개 문의에 올리지 마세요.

1. 알림 접근과 사용 목적
사용자가 동의하고 Android 알림 접근을 허용하면 카카오톡 알림의 대화 식별 정보와 최신 메시지를 기기 안에서 확인합니다. 앱이 화면에 보이지 않을 때도 연결한 대화의 명령에 응답하고 등록한 알림을 전송합니다. 다른 앱의 알림은 처리하지 않습니다. 방 연결 중에는 새 카카오톡 알림에서 정확한 일회용 코드와 대화 식별 근거를 검사합니다. 연결한 이후에는 확인한 대화만 처리합니다.

2. 저장하는 정보
기기에 방 이름·대화 식별 해시·기능과 말투 설정·등록한 알림을 저장합니다. 중복 처리를 막는 메시지 해시, 전송 내용·상태·시각과 오류 구분을 저장합니다. 뽑기 후보처럼 사용자가 입력한 정보가 답장 내용에 포함될 수 있습니다. 전체 대화 이력과 다른 방의 메시지를 대화 기록으로 보관하지 않습니다. 답장에 쓰는 임시 정보는 메모리에만 보관합니다.

3. 전송과 제3자
앱은 자체 서버로 대화를 업로드하지 않으며 광고·분석 SDK를 사용하지 않습니다. 사용자가 켠 기능의 답장과 예약 알림은 카카오톡을 통해 해당 대화 참여자에게 전송됩니다. 카카오톡과 Android의 서비스 처리에는 해당 제공자의 정책이 적용됩니다. 문의 링크나 웹 처리방침을 열면 외부 브라우저·서비스가 처리합니다.

4. 보관과 삭제
방 설정·등록 알림은 사용자가 삭제할 때까지 보관합니다. 7일 지난 완료 발송 기록과 1일 지난 중복 확인 값은 앱 동작 시 정리합니다. 최근 처리 기록은 최대 100개를 보관하며 7일 지난 기록은 앱 동작 시 정리합니다. 설정의 ‘이 방 설정 삭제’ 또는 ‘앱 데이터 모두 삭제’로 기기에 저장한 데이터를 삭제할 수 있습니다. 앱 제거로도 앱의 로컬 데이터가 삭제됩니다. 이 앱은 Android 앱 데이터 백업을 허용하지 않습니다.

5. 동의 철회
설정의 ‘알림 사용 동의 철회’로 처리와 발송을 중지할 수 있습니다. 저장 데이터는 별도로 삭제할 때까지 남습니다. Android 설정에서 알림 접근 권한을 해제할 수도 있습니다. 동의 철회는 이미 카카오톡으로 전송된 메시지를 삭제하지 않습니다.

6. 보호 조치와 변경
앱 전용 저장소를 사용하고 알림·전송 대상을 확인합니다. 앱에는 인터넷·연락처·위치·파일 전체 접근 권한이 없습니다. 데이터 처리 방식이 바뀌면 처리방침과 필요한 동의 화면을 갱신합니다. 문의 시 필요한 범위의 정보만 보내 주세요.
